Mão na massa

As fundações técnicas para construir seu AI OS com memória persistente: Letta, A-MEM e AIOS — todos open source.

FundaçãoEscolhendo a base de memória

Um AI OS precisa de uma camada de memória que sobreviva entre sessões e se mantenha organizada. Três projetos open source cobrem isso hoje, cada um com um ângulo diferente. Role para baixo para decidir por onde começar.

L

Letta (MemGPT)

Agentes stateful que lembram tudo. Abstrai a complexidade da memória para você focar em lógica.

A

A-MEM

Memória que evolui sozinha (método Zettelkasten). Conecta aprendizados automaticamente.

O

AIOS

LLM como SO: gerencia agents como processos, com scheduler, memória e contexto.

Framework 1Letta — agentes com memória stateful

  • Letta — site oficial
    "Machines that learn." Cria agentes stateful que lembram tudo, aprendem continuamente e melhoram com o tempo.
  • Letta — repositório GitHub
    Código aberto (antigo MemGPT), centenas de contribuidores. Implementa o design de memória de longo prazo em LLMs.

Como encaixa na arquitetura

1

Memória hierárquica

Letta separa memória de longo prazo (arquivada) da de trabalho (contexto ativo) — exatamente as camadas 2 e 3 do nosso diagrama.

2

Self-editing memory

O agente decide o que memorizar e o que descartar, reduzindo contexto obsoleto.

3

Ponto de partida

É o caminho mais direto para ter um agente com memória rodando localmente — etapa 5 do passo a passo.

Framework 2A-MEM — memória que evolui sozinha

  • A-MEM — paper (arXiv:2502.12110)
    Sistema de memória agentica que organiza memórias dinamicamente. Baseado no método Zettelkasten de notas conectadas.
  • A-MEM — repositório GitHub
    Código aberto do paper. Boa referência para quem quer implementar "insights acumulativos" (camada 4).

Por que importa para o nosso OS

O A-MEM é a materialização técnica do conceito de insights acumulativos: em vez de apenas empilhar fatos, ele cria uma rede de conhecimento onde novas memórias se conectam às antigas. É o que faz o sistema "ficar mais esperto" com o uso — alinhado à tese do G4 de contexto que cresce.

Framework 3AIOS — LLM como sistema operacional

  • AIOS — repositório GitHub
    Implementação real de "LLM como SO": gerencia agents como processos, com scheduler, memória e contexto. Veja código de um OS de IA funcionando.

O que ele representa

Se o Letta é sobre memória e o A-MEM sobre organização, o AIOS é sobre orquestração em nível de SO: como múltiplos agents convivem, recebem recursos e são escalonados. É a referência mais próxima de um "sistema operacional" de verdade para IA.
